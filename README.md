# dusk-wallet-js
JavaScript library for rusk-wallet

This will be later grafted into js-utils repo

## NPM scripts

* `npm run docs`: generates the documentation in the `./docs` folder.
* `npm run lint`: runs linting for code and test, in sequence.
* `npm run lint`: performs the linting checks
* `npm run lint:fix`: runs ESLint with the `--fix` flag to fix formatting errors
* `npm test`: runs the test suite.
* `npm run test:coverage`: runs tests and generates the code coverage report in `./coverage`.
* `npm run typecheck`: performs the TypeScript type checks
